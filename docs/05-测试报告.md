## 真实模型验证

用本机 Ollama（`minicpm5-2b:q8-64k` 抽取 + `bge-m3` 向量）：

| 输入 | 抽取结果 | 判定 |
|---|---|---|
| 我在字节跳动做后端，三个月前刚跳过来的 | `工作在 字节跳动` + state job | 正确 |
| 说实话我不太喜欢猫，主要是怕毛 | `喜欢 猫` polarity=**-1**、`害怕 毛` | 否定正确 |
| 今天天气不错啊 | 0 条 | 正确拒抽 |

**延迟**：首次 50.5s（模型加载），之后 10.3s / 1.7s。这个数字直接推出了"写入必须异步"的设计。

## 性能（评审后复测）

| 操作 | 评审前 | 评审后 |
|---|---|---|
| 写入接收（异步路径） | 16.1s（实际同步阻塞） | **50ms** |
| 检索（200 条 / hash 向量） | 625ms | **1ms**（中位 20 次） |
| 检索（9 条演示库） | 856ms | 2.9ms |
| 全量测试 | 3.5s | 0.7s |

改善来自三处：thread-local 连接复用（原来每次操作新建连接，单次 5.9ms，其中 WAL PRAGMA 占 5.2ms）、WAL PRAGMA 只在建库时设一次、`ensure_tables` 移出读路径。
