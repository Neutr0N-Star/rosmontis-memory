# 产品文化 · Rosmontis

> 这份文档只做两件事：给已有的结构起名，说明哪些名字不能起。

## 一、为什么叫 Rosmontis

叫 Rosmontis，是因为这套系统只做了阿赖耶识的三件事——受熏、持种、异熟；没有了别，没有相续，也没有实我。

| 项 | 对应 |
|---|---|
| 受熏 | 被写入。一次对话改一次库。 |
| 持种 | 存储。断言留下，等下一次缘。 |
| 异熟 | 延迟成熟。折叠与归纳的果，不在因的当下。 |
| 没做的 | 了别、相续、执我。所以它是藏，不是识。 |

名字取功能，不取实体。这是全文的前提。名字的准确性止于功能层；再往下问「它是不是识」，答案是否定的。

凡是把 Rosmontis 说成「一个心」的地方，都是错的。

## 二、两层命名

| 层 | 用什么 | 给谁看 |
|---|---|---|
| 工程层 | 英文工程词：`episode` `fact` `state_slot` `promote` | 接手的工程师 |
| 概念层 | 中文概念名：本事、种子、现在、入位 | 维护者、架构文档、界面、日志 |
| 对外层 | 只说功能，不用隐喻 | 用户 |

三条规矩：

1. 工程层不改。表名、字段、接口路径、函数名保持英文。改一次，历史 issue、日志、迁移脚本全部对不上。
2. 概念层不翻译，只对应。一个工程结构一个概念名，反过来也一样。名字是坐标，不是修辞。
3. 概念名不超过三个字。超过三个字，是解释，不是名字。

日志的写法：`event=fold concept=折叠`。键给 grep，名给人。

文档标题示例：「种子与现行」，不写「Fact 与 Context」。界面模块：应缘、案头、现在、名册、假我。

## 三、唯识概念 ↔ 工程结构

判定用三把尺：

- 结构同构，不是词义相近。
- 能解释一个已经做出的工程决策。解释不了的，是装饰。
- 借过来不会让人误解机制。

三条全过，才算能对应。前两条过、第三条存疑，算部分对应。只满足词义相近，算不能对应——列出来是为了禁止后来者借用。

| 判定 | 唯识概念 | 工程结构 | 理由 |
|---|---|---|---|
| 能对应 | 能藏 | schema、表、索引 | 结构决定什么存得下。改表就是改能藏的边界。 |
| 能对应 | 所藏 | `episode` / `fact` 等行 | 被持的内容本身。 |
| 能对应 | 种子（未现行的功能差别） | `fact` | 断言未注入时只是潜势，遇一次提问才现行。检索因此不直接翻原文。 |
| 能对应 | 熏习 | 写入管线、召回强化 | 现行回写种子：对话改事实与现在，不改人格。差别是可审计——每条事实都有 `source_episode`；唯识的熏习无始且不可观察。 |
| 能对应 | 现行 | 本轮注入的上下文 | 种子在缘具时显现为当下。每轮重建、不落库，对应刹那灭。 |
| 部分对应 | 阿赖耶识 | 整个持久层 | 受熏、持种、异熟三项对得上；没有了别，没有相续的识流。名字取功能，不取识体。 |
| 部分对应 | 异熟 | 折叠、后台归纳 | 异时而熟、异类而熟、变异而熟，都对得上：果不在因里，晚于因，形态不同。但异熟是业报，有承受者；折叠只是压缩。只借延迟，不借果报。 |
| 部分对应 | 第六意识 | 抽取、查询理解（LLM 层） | 分别、构画、安立名言对得上。但第六识属于心识相续；模型每轮重建。 |
| 部分对应 | 末那的排他性 | 人格预算独立 | 自我不能被别的东西挤掉，这一点对得上。机制不同：一边是烦恼，一边是预算隔离。 |
| 不能对应 | 前五识 | ——（硬套则是多模态 adapter） | 系统只有一个文本入口。没有根，没有境，没有现量。五个 adapter 叫五识是装饰。 |
| 不能对应 | 第七末那识（作为识体） | —— | 末那恒审思量、自动执我，是烦恼。系统没有持续心识；人格是每轮编译的文本，且由人授权。叫末那，等于说核心功能是病。 |
| 不能对应 | 我爱执藏 | —— | 这一藏成立的前提，是有末那把它执为我。没有末那，它无处安放。 |
| 不能对应 | 种子（业种子义） | —— | 同一个词的第二层含义。业种有善恶、能感苦乐；`fact` 只是命题，没有道德效价，也不产生体验。 |
| 不能对应 | 业力 | `salience` | 业有善恶、通三世、能感果。`salience` 只是排序权重。这是最容易被写进文案的一处硬套。 |
| 不能对应 | 转识成智 | —— | 不可逆的转依事件，不是功能。系统的「见」带证据链、可撤回，仍是识。借这个词等于替产品宣称开悟。 |
| 不能对应 | 有漏 / 无漏 | —— | 系统里没有无漏法：没有一条记忆豁免于订正，连删除都要留碑。把 `pinned` 叫无漏，是把预算保护说成究竟。 |
| 不能对应 | 名色 | `entity`（若硬套） | 名色专指有情的名与色，不含地点与物件。实体层的问题是消歧，不是认识论。 |

三藏是结构面，受熏、持种、异熟是功能面。两面都有对应；对不上的是识体与执藏。这不是遗漏。产品要的是一个稳定的人格，不是一个能执我的心。

硬套的代价不是显得装，是让后来的人按错的类比改代码。

## 四、命名总表

| 工程名 / 结构 | 概念名 | 一句话解释 |
|---|---|---|
| `episode` | 本事 | 发生过的原话，不改。改的永远是解释。 |
| `fact` | 种子 | 从本事抽出的断言；未注入时只是潜势。 |
| `entity` | 名册 | 能被断言指向的东西。这层的问题是消歧，不借唯识词。 |
| `hyperedge`（theme） | 共相 | 多条本事共有的东西。n 元归组，不是两两连边；归纳物，不是原文。 |
| `state_slot` | 现在 | 此刻生效的那一版世界。由种子算出，不是另一份记忆。 |
| `persona` | 假我 | 她是谁的一份施设。可改，但不能被预算挤掉。 |
| `page` | 案头 | 预写好的四页，摆在桌上。每轮直接读，不检索。 |
| `observation` | 见 | 从多条种子得出的结论。是见不是事实，所以带证据、可撤回。 |
| 写入管线 `write` | 熏习 | 一条本事进来，改种子、改现在；不改假我。 |
| 检索 `recall` | 应缘 | 问题为缘，取种子与现在，合成现行。 |
| 注入块 | 现行 | 本轮真正进入上下文的那一段。用完即弃。 |
| `resident` / `state` / `retrieval` | 常驻 / 现在 / 浮现 | 三档注入：必定现、此刻现、缘熟而现；人格预算另立。 |
| `decay` → `fold` → `archive` | 退失 → 折叠 → 归档 | 力弱、压成一条、移出热区。三级都不删数据。 |
| `tombstone` | 碑 | 删除留碑，不可复活。 |
| `promote` | 入位 | 进不进常驻，由作者、类型、确认决定；工具行为永远不进。 |
| `t_valid` / `t_ingest` | 事时 / 知时 | 事何时为真 / 系统何时知道、何时判定失效。两个时间不能合并。 |
| `L0`–`L3` | 渐显 | 同一件事四级存放，从最省的一级开始用。 |

三条注：

**假我不是「虚假的我」。** 它是依名言施设的我，与「实我」相对。系统有前者：一段可改、可编译、受 7600 字符约束的声明。系统没有后者：没有一条记忆归属于一个实我。假我声明她是谁，不回答谁在声明。假我不受熏习——人格由人写入、由预算保护，对话不会自动改写她是谁。

**`state_slot` 不叫现行。** 表落库，带 `since` / `until`，三个月前的值还能回查；现行只存在一轮，用完即弃。把表叫现行，等于把刹那说成持久。现行这个名字给本轮注入的上下文——那才是真正显现的东西。

**遗忘不叫熏习衰减。** 熏习是现行回写种子，方向是「改」；衰减是久不遇缘，方向是「弱」。把衰减叫熏习，会把双向环压成单向，还会让「熏习」同时表示加强和减弱。第一阶段用退失。

## 五、三条边界

### 边界一：隐喻不能替代机制

规则：任何对外句子，删掉隐喻后必须仍然成立。

反例：「它会像Rosmontis一样记住你。」删掉比喻，什么也没说。

正例：「它记得你现在住哪，也记得你三个月前以为你住哪。」

对外文案里出现「识、种、熏」三个字，就要重写。

### 边界二：不给系统安「识」或「我」

规则：主语只能是具体结构——这条事实、这份快照、这次注入、这个结论。

反例：「它把自己当成我」「它熏出了新种子」「它转识成智了」。

正例：「这条事实被写入」「这次注入用了四条」「这个结论的证据是这三条」。

一旦它有了「我」，产品就要为它的感受负责。它没有感受。

### 边界三：一词只指一层

规则：新名字进表前先查冲突；冲突就换词，不换定义。

现在 ≠ 现行。种子 ≠ 本事。见 ≠ 事实。置信度 ≠ 信。重要度 ≠ 业力。

排障时名字是坐标。一个词指两层，两层同时失焦。

## 六、系统自述

用在 README 开头，47 字（含标点）：

> Rosmontis：把对话存成原话，把原话抽成断言，把断言算成现在；可回溯，会遗忘，删除不复活。

自述用工程白话，不用概念名。README 的读者要先知道它做什么，再决定要不要往下读。
