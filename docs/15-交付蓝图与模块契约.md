## 0 第一性原理：记忆系统的三个不可再分的量

1. **记忆是有状态的对象**（不是一条条等距的文本）：它有身份、有生命周期、会失效、会改主意。
2. **回忆是有成本的检索**（不是 top-k）：在有限预算下最大化价值，成本必须可计量。
3. **记住与忘记是同一个过程的两端**（不是两个功能）：写、衰减、归档、折叠由同一套动力学决定。

推论（本文据此立契约）：
- 对象唯一 → `item` 是唯一记忆对象，主/被动只是 `origin`。
- 检索唯一 → **语义场**是唯一检索入口，向量只是点火器。
- 生命周期唯一 → 状态机 + 场动力学是唯一真值。

## 1 语义场（Semantic Field）：把向量库升级成场

### 1.1 定义

场 = 图（结构）+ 向量（相似）+ 时间（衰减）三者的统一表达。

- **节点**：item（episode 派生）与投影物（entity/fact/state_slot/hyperedge）。
- **边**：三类，权重可衰减
  - 结构边：hyperedge 成员关系（现有表，权重 = member.weight）
  - 共现边：同一 episode 中抽出的实体对（稀疏，构建一次）
  - 语义边：向量 kNN（k=8，余弦 > 0.72），**不落库**，查询时按需构建，避免近似索引维护
- **激活**（ACT-R 幂律，替代裸 `access_count` 加成）：
  `A_i(t) = ln( Σ_j (t - t_j)^-0.5 ) + B_i`，实现取 `B_i = 2 · salience`（系数 2 无文献依据，属待标定参数，见 B5 审计 §5）
- **扩散**（离散版 `D∇²φ`，**凸组合形式，保证有界收敛**）：
  `φ ← (1 − α)·φ + α·D⁻¹A·φ`，迭代 ≤3 次，`α` 为混合系数（实现固定 0.45）
  - ⚠️ 早期草案写的 `φ ← φ + min(α,1)·D·L_norm·φ` 在 α=0.45 时实测发散（二部图特征值 −1 处放大 1+2α，六步从 1 涨到 24），**以本式为准**（B5 审计 §1.2 有数值验算）
  - 用稀疏乘法实现，复杂度 O(E × iter)，禁止稠密矩阵
- **三空间衰减率**：`identity 0.1 / knowledge 1.0 / operational 3.0`
  - 已接线到 `score.py`（激活 × 空间倍率）与 `forget.py`（retention 的 Δt 乘倍率）；但三处口径（score / forget / memory_field）尚未统一口径换算，且 0.1/1/3 这三个数**未查到文献依据**，属待标定（B5 审计 §1.3）
  - 空间归属：persona/identity 条目 → identity；fact/state/entity → knowledge；会话进度、冷却、工具行为 → operational

### 1.2 检索 = 场点燃 + 预算贪心（四步）

```
1. 点火：query → 种子集 S
   - embedding kNN（top 24）
   - FTS5 关键词（top 24）
   - 实体命中（plan 里解析出的实体，1 跳邻域）
2. 扩散：从 S 出发按 §1.1 迭代，得到候选激活 φ
3. 打分：保留现有 rel/time/salience/graph/emotion 分项（docs/03 §4.3 不动），
   把 access_count 项替换为 A_i(t)，并乘空间衰减系数
4. 打包：现有 L0–L3 四级 + 边际收益贪心 + 绝不超预算（docs/03 §4.3b 不动）
```

**判据**：向量只决定"从哪里点亮"，不直接决定排序。删掉向量路后场仍能工作（FTS+实体点火），只是种子质量下降。

### 1.3 场的内置保护

- 冷启动：无结构边时退化为纯向量/FTS 点火，扩散跳过（不得报错）。
- 空场：种子为空 → 按现有拒答逻辑 abstained，不扩散。
- 环路：迭代次数上限 3，超限截断，不进死循环。
- 可解释：每次检索写入 `retrieval_log` 的 `plan_json` 记 `seeds / iterations / edge_types / phi_top`。

## 2 帕累托优化：质量 vs 成本，两轴都要可测

### 2.1 指标（每项都要有采集脚本，不得手工报数）

| 轴 | 指标 | 采集方式 |
|---|---|---|
| 质量 | 抽取记对率 P、记全率 R、F1 | golden set 人工标注（200 段） |
| 质量 | 召回 nDCG@10 / 时序 / 多跳 / 更新 / 偏好 四类准确率 | 题集 + 判定脚本 |
| 质量 | 拒答误召率、漏召率 | 标注集 + 阈值扫描 |
| 质量 | 人格漂移率（200 轮 identity 不变） | 长程脚本 |
| 质量 | 场增益：扩散带来的新增相关命中比例 | 对比「关扩散 vs 开扩散」 |
| 成本 | 注入 token、检索延迟 p50/p95、写入延迟、LLM 调用次数、单会话成本 | benchmark 脚本落 JSON |

### 2.2 帕累托纪律

- **基线纪律**：所有基线只在**库副本**上跑，记录副本 `sha256` 与固定 `now/as_of`；`Memory.recall` 默认写库（`retrieval_log`、`access_count`、`cooldown`）且**不提供只读开关**，因此一律用副本 + 冻结时钟。**禁止「对真库只读回放」这种说法。**
- **支配判定**：配置 B 支配 A，当且仅当 B 在所有质量指标 ≥ A，且所有成本指标 ≤ A，且至少一项严格更优。
- **改动准入**：任何影响检索/抽取/预算的改动，必须给出「改动前后在同一基准集上的支配关系」。做不到就说明改动不可评估，不许合。
- **前沿报告**：`bench/report.md` 由脚本生成，列 6–10 个配置的帕累托前沿（扩散强度 × 深度 × 预算）。
- **不得**用「感觉更好」代替数字；**不得**引用别家 benchmark 数字（未跑自己的）。

### 3.5 jobs 表与节拍契约（W4 实现，M7a 的前置）

```sql
CREATE TABLE IF NOT EXISTS job (
    id           TEXT PRIMARY KEY,          -- 确定性键：kind + 主体 + 窗口
    kind         TEXT NOT NULL,             -- enrich | review | dream | settle | forget | backfill
    target       TEXT NOT NULL,             -- item_id / session_id / space
    status       TEXT NOT NULL,             -- pending | running | done | failed | dead
    attempts     INTEGER NOT NULL DEFAULT 0,
    max_attempts INTEGER NOT NULL DEFAULT 3,
    next_run     REAL NOT NULL,             -- 下次可执行时间（epoch 秒）
    lease_owner  TEXT,                      -- 选主：持有租约的 worker
    leased_until REAL,
    last_error   TEXT,
    created_at   REAL NOT NULL,
    updated_at   REAL NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_job_due ON job(status, next_run);
```

- `idle_timeout`：会话空闲多少秒后自动 settle，默认 **1800 秒**，配置项 `Config.idle_timeout_s`。
- 调度约束：单写者队列（同一 job 同时只允许一个 worker）；失败退避 `min(2^attempts, 300)` 秒；超过 `max_attempts` 进 `dead` 并告警；启动时扫 `status='running' AND leased_until < now` 收回。
- 幂等：`id` 由 `kind + target + 时间窗` 确定性生成，重复投递不产生第二条。
- M7a/M7b 的判据依赖本表，未落库前不得判定（见 docs/14 §3）。

### 3.6 Embedder 契约

向量检索是核心能力。Embedder 的契约分四块：

**（1）通道**

| `ALAYA_EMBED` | 依赖 | 定位 |
|---|---|---|
| `local` | `onnxruntime` + `tokenizers`（extras `[embed]`）+ 已下载模型 | 无外部服务的真实语义向量 |
| `openai` | 无（复用 `ALAYA_OPENAI_BASE/key/model`） | 已有 OpenAI 兼容通道时复用 |
| `ollama` | 本地 Ollama | 默认通道 |
| `hash` | 无 | **仅测试/离线演示**；余弦无语义意义，检索跳过 rel 门 |

落地状态：断路器、向量身份（v4）、`embed_backfill` 已落地；`local` / `openai` 通道随 v1.1；`ollama` / `hash` 当前可用。

**（2）向量身份**

`episode` 与 `fact` 记录 `embed_model`（模型标识）与 `embed_dim`（维度）。检索只比较**同身份**向量；两列为 `NULL` 的历史数据按「未知身份」处理，仍可参与检索，不报错。换模型/换维度后旧向量不再静默混用。

**（3）降级与可恢复性**

- 连续失败后进入 `unavailable`：**不再发起远程请求**，直接走 fallback（避免半死服务把每轮拖成 8 秒级等待）；指数退避后重探，恢复后自动切回。
- 降级期写入不落向量（`embedding IS NULL`），由 `embed_backfill` 任务在恢复后补齐——降级可以发生，但不能不可逆。
- `hash` 不是对外正式运行模式。

**（4）模型资产**

模型不进 wheel。安装器 `alaya models install <name>`：断点续传（`.part`）、最多 3 次重试、SHA-256 校验通过才替换、失败保留旧模型；目录默认 `~/.alaya/models/`，可用 `ALAYA_MODEL_DIR` 指定；镜像 `--mirror` / `ALAYA_MODEL_MIRROR`。

**（5）可观测**

`/readyz` 与 `stats()` 输出 `vector_mode`（`semantic` / `degraded` / `none`）、`embed_model`、`pending_backfill`。
