# 接入形态与接口方案（前端在体外）

> 状态：v1 · CEO 已定边界（2026-10-19）：**前端完全不在本产品内**；本系统只做后端，必须提供通用接口让别人（前端 / 别的 agent / MCP 宿主）能用。
> 本文回答三个问题：别人怎么接进来、我们承诺什么、分几期做。技术细节见 `docs/15-交付蓝图与模块契约.md`，不重复。

---

## 0 一句话定位

**Alaya 是「记忆运行时」：一个可嵌入的库 + 一个本地服务 + 一个 MCP 网关。前端是它的消费者，永远在体外。**

推论：任何前端（自研、LingChat、其他开源项目）都只通过**接口**用我们，不 import 内核、不碰数据库。换前端不需要改后端；这也是为什么前端选型现在不影响本项目的进度。

---

## 1 三种接入形态（这就是"通用接口"的全部）

| 形态 | 谁用 | 接入成本 | 能拿到什么 | 稳定性承诺 | 优先级 |
|---|---|---|---|---|---|
| **① Python 库**（`pip install alaya-memory`） | 自建 Python agent、陪伴类产品后端 | 3 行：`open()` → `wake/turn/settle` | 完整能力：四钩子、纯函数 `context`、工具链、状态机 | API v1 冻结 | M0 |
| **② HTTP 服务**（`alaya serve`） | 任何语言的后端、前端、桌面壳 | 一个 REST 端点表 | 完整生命周期 + 管理接口（state/timeline/episodes/settle） | 契约 v1 冻结 | **M0/M1 主线** |
| **③ MCP 网关**（`alaya mcp`） | Claude Code / Cursor / 任何 MCP 客户端 | 装一个 server，零代码 | 工具 + 只读资源；**拿不到 wake/sleep 自动注入** | 工具名稳定，语义 v1 | M1（获客渠道） |

**为什么主线是 ②、而不是 ③**：MCP 客户端不会为记忆改自己的对话循环，所以「每轮常驻注入」「会话结算」这类最值钱的能力拿不到（只能拿到检索工具，估五到六成价值）。MCP 是入口，不是本体；真正的产品形态是本地服务 + 库。

---

## 2 MCP 网关设计（MVP）

- **传输**：`stdio`（本地宿主直接用）+ `streamable HTTP`（远程，需 token）。
- **工具（默认只读，写要显式开启）**：
  - `memory_recall`（查）、`memory_state`（当前状态快照）、`memory_timeline`（某实体变更史）、`memory_status`（库规模/降级状态）
  - 写类（`memory_remember`/`memory_note_*`/`memory_skip`）默认关闭，启动参数 `--allow-write` 才暴露——MCP 宿主不该默认拥有改记忆的权限。
- **资源**：`alaya://persona`（人格块）、`alaya://state/{scope}`、`alaya://resident`（常驻活文档），只读。
- **不暴露**：`wipe`、`settings`、迁移、删除——危险操作只留在本地 CLI。
- 复用现有 `tools.py` 的五个工具与 `dispatch`，映射层约 100–150 行，不新写记忆逻辑。

## 3 前端怎么接（前端不在本产品，但必须能接）

前端只允许做三件事：

1. **说话**：`POST /v1/turn`（或自己持有循环，每轮调 `/v1/context` 注入 + `POST /v1/observe` 回写）。
2. **看**：`GET /v1/state/{scope}`、`GET /v1/episodes`、`GET /v1/items/{id}/state`、`GET /v1/timeline/{entity}`。
3. **打烊**：`POST /v1/session/sleep` 或 `POST /v1/settle`（触发结算/整理/做梦）。

禁止：前端直连 SQLite、翻 `web/` 之外的内部模块、拼记忆提示词。违反这三条，换前端就得改内核。

## 4 契约与版本纪律

- **冻结面（v1）**：`alaya.open` + `Handle.{wake,context,turn,observe,settle,close}`、五个工具名与六键返回、`/v1` 下 README/guide 列出的端点、统一错误信封 `{ok,data,error{code,retryable,message}}`。
- **不承诺面**：`Handle.cfg/mem/harness/job`、`pipeline.*`、`field.*` 内部签名（文档标注"非稳定"）。
- **破坏性改动**：升 `api_version` 主版本；schema 改动走 `open(migrate=...)`，默认先备份。
- 三处版本号（包版本 / API 版本 / `PRAGMA user_version`）由单一来源派生并加测试断言。

## 5 分期

| 期 | 交付 | 出口标准 |
|---|---|---|
| **M0（约 1 周）** | 打包发布（pip + extras）、`alaya backup/restore`、`open(migrate=...)` 安全开关、README 重写为接入优先、CI | 外部人 30 分钟从零接上自己的 agent |
| **M1（1–2 周）** | HTTP 契约冻结 + `alaya daemon`（自动节拍/空闲结算）+ **MCP stdio server（只读默认）** | 前端/宿主换一个不需要动内核；无人操作时节拍自己跑 |
| **M2（按需）** | MCP HTTP + token 鉴权 + `space/conversation` 两层隔离 | 能给多个用户/多个前端共用一个服务 |

---

## 6 明确不做

- 不做前端（含任何界面、桌面壳）；前端选型不进入本项目范围。
- 不做 prompt 模板（说话风格归宿主）。
- 不在 MCP 里暴露危险管理接口。
- 不做多 agent 协调（单会话单 agent，编排归宿主或上层框架）。
