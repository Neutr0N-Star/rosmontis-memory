# B2 产品样态审计

> 审计对象：`D:\MyHub\06-Projects\alaya-memory`（HEAD `b862633`，工作区除 `bench/_profile/` 外干净）。
> 判据只有一个：**外部团队今天拿到仓库，能不能 30 分钟内跑起来并接进自己的 agent。**
> 方法：`docs/15-交付蓝图与模块契约.md` 逐条对仓库 + 干净副本实测（复制到系统临时目录，不改代码、不写 `alaya.db`、不碰 `web/`、不 commit）+ 只读打开 `alaya.db` 查版本。实测记录见 §9。

## 0. 结论

1. **跑得起来，但只到「跑 demo」这一档，不到「能交付」这一档。** 干净副本里 6 套测试 93 项全绿（约 5 秒）、离线 demo 0.6 秒、bench 评测 1.4 秒——内核与验证资产是好的。
2. **卡点不在代码，在交付面：** 仓库没有 `pyproject.toml`，`pip install -e .` 直接报「does not appear to be a Python project」；没有 `python -m alaya`；README 仍只教 `python run.py` 和旧 `Harness`，真正可用的公共 API v1（`alaya.open()` + 四钩子 + `examples/hooks_demo.py`）在 README 里**零出现**。
3. 第二层卡点：`examples/hooks_demo.py` 在 Windows 默认 GBK 控制台**第一屏就 UnicodeEncodeError**（实测），必须 `PYTHONIOENCODING=utf-8` 才能跑通，而这个前提只写在 A7 报告里，没写进示例。
4. `docs/15` 与仓库的偏差集中在三处：状态行过期（WS-B/C/D 写「进行中」，实际已落盘）、§3.4 错误码表**是空段**、§3.5 jobs 表 / `idle_timeout` **只有契约没有实现**，导致验收项 D4a/D4b 当前必然不通过、D5 已被 A8 明确判「未通过」。
5. 运维面接近空白：`/health` 是静态 `{ok, ts}`，无 readiness、无版本；无 lifespan/优雅关停；无可执行的备份/恢复命令，而真库 WAL 有 **4.3MB 未 checkpoint**，按 README「单文件备份」直接复制会丢数据。
6. 法律与信任面空白：**无 LICENSE**（外部团队默认无权使用）、无隐私声明、无删除权说明、无版本/兼容承诺（无 tag、无 CHANGELOG）。
7. 两周可做完的最小集：**8 条核心 + 2 条可选，约 6–7.5 人日（核心只做 P0 四条 ≈ 3 人日即可让外部团队 30 分钟内跑通并接上自己的 agent）**，详见 §7。jobs/daemon、鉴权、MCP、真实 LLM 评测不在两周内（§8）。

## 6. 竞品的产品样态差距（只谈形态/接口，不重复 A3 调研）

| 形态 | 竞品做法 | 我们的现状 | 差距性质 |
|---|---|---|---|
| 安装 | 多数竞品 `pip install`/`npm` 一条命令，版本化发布 | 无 pyproject、无 tag、只能 vendoring 源码 | 交付基础设施 |
| 首跑 | 官方 quickstart：装包 → 填 key → 一条 curl/十行 SDK 出结果（[Mem0 平台 quickstart](https://docs.mem0.ai/platform/quickstart)、[Letta quickstart](https://docs.letta.com/quickstart)、[Cognee 文档](https://docs.cognee.ai)） | README 首跑是 `python run.py demo`（本仓库内），不是「接进你的应用」 | 文档与示例 |
| 接入面 | 稳定 SDK + REST + MCP/插件，错误码与重试语义公开 | 库形态有 API v1 但不可发现；服务形态仍是旧同步 `/v1/turn`、`/v1/session/sleep`，无 hooks 端点 | 接口收口 |
| 运维 | 托管后台：用量、错误、日志、配额 | 本地无仪表盘、无 `/metrics`、无成本台账 | 可观测 |
| 许可 | 明确 LICENSE + 商业边界（开源 vs 云） | 无 LICENSE、无商业边界声明 | 法务前置 |

一句话：竞品卖的是「装得上、连得通、看得见」的交付面，我们目前只有「引擎 + 内部契约」。差距不在记忆模型。

## 7. 两周内能做完的产品化最小集（按投入产出排序）

> 口径：1 名熟悉仓库的工程师 × 10 个工作日；每条含实现+自测；P0 = 不做则 30 分钟判据必然失败。

| 序 | 条目 | 投入 | 产出 | 验收（可独立判定） |
|---|---|---|---|---|
| 1 | **pyproject + extras + `__main__` + console script** | 0.5–1 d | 可 `pip install -e ".[server,dev]"`；`alaya`/`python -m alaya` 可用 | 干净 venv 三条命令全过；`pip install -e .` 不装 fastapi 仍能 `import alaya` |

| 3 | **LICENSE + 隐私/删除声明** | 0.3 d（+决策） | LICENSE、PRIVACY.md、README 许可段 | 外部团队可合法试用；删除路径有文档 |

| 5 | **错误码统一（`errors.py` + 文档表 + `fail()` 补 retryable）** | 0.5 d | 库/HTTP 一套码，调用方可判重试 | 测试扫描 code 全在表内；错误响应含 retryable |
| 6 | **`alaya backup` / `restore`（含 WAL checkpoint）** | 1 d | 可靠备份恢复命令与文档 | 写入中备份副本 integrity_check=ok；restore 后 audit 正常 |

## 8. 两周内明确不做（并说明理由）

- **jobs 表 + 守护进程 + 租约选主**：3–5 人日，且依赖 space/鉴权一起改；已有 A3-M0 计划，单独立项，避免两周最小集失焦。
- **`space_id` 两层隔离 / Bearer 鉴权 / 配额**：改动贯穿存储与 recall，属 M0 后半；两周内只保留「loopback only」警告。
- **MCP 适配器 / OpenAI 插件**：是分发渠道，不是交付阻断（A3 M1）。
- **真实 LLM 抽取质量评测 / 人工标注集**：需要模型与标注资源；bench 已有合成集，A8 已声明局限，两周内不扩。
- **`/metrics` 之外的监控栈（Prometheus/Grafana）、告警**：本地单机阶段过重。
- **PyInstaller/桌面壳、Docker 镜像、Postgres**：形态选择在 A3 M3，不在本周。
- **`web/` 的任何改动**：本轮审计约束，且不是产品化主路径。
