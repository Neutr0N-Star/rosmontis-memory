## 0 五条结论

1. **最站不住的一条**：docs/15 §1.1 的扩散式 `φ ← φ + min(α,1)·D·L_norm·φ` 及其「凸组合 ⇒ 有界」的论证。按行归一化解读（`L_norm = I − D⁻¹A`）它等价 `(1+α)φ − αD⁻¹Aφ`，不是凸组合；二部图特征值 −1 处放大 `1+2α`，实测 α=.45 迭代 6 步从 (1,0) 涨到 (24.02, −23.02)（若 D 是度矩阵而非倍率，只会更不稳定）。代码实际写的 `(1−α)φ+αD⁻¹Aφ` 才是稳定式（6 步收敛到 (.5,.5)）。**学理陈述与实现各说一套**。
2. **最刺眼的文档-代码相反**：docs/10 §六 判定「情绪不再直接提权」，代码正好相反——`w_emotion=0.18` 仍在打分里（`score.py:210`），`salience` 也含 `emotion×0.30`（`write.py:547`）。理论把「情绪提权」认定为祥林嫂的放大器，实现却保留了这个放大器；且没有任何「待消化队列」承接情绪。
3. **最值得补的理论环节**：**来源监控（source monitoring）**。docs/00 P2 的硬证据是「她会把别人写的字当成写给自己的话」；系统只在存储层有 `author/source/confirmed`，注入块 `<memory>` 里一个都不显示（`recall.py:996-1020`），升格闸门却拿它当判据——信息在环节之间断了。
4. **最贵的未落地主张**：「关键节点永不归档」「梦的抽象产物进升格/观察链」「resolved 消化态」「fact 也衰减归档」「名字占位符」五条，全部只有文档、字段或空函数，没有执行路径（详见 §2）。
5. **参数只能靠真语料**：θ_abstain（现值 0.18，属猜值；合成基准建议 0.50）、salience 的 7 个常数、衰减基数 21 天与 0.08/0.25 阈值、三空间 0.1/1/3、扩散 α=0.45、ACT-R 的 B=2·salience——全部没有真实语料或文献数值依据（§5.2）。

## 1 公式核对

### 1.1 ACT-R 幂律：形式对，边界与常数不对

**形式对照**（ACT-R 基础激活；教程入口见 §3 文献表）：

| 项 | 标准 ACT-R | 本项目实现 | 判定 |
|---|---|---|---|
| 公式 | `A_i = B_i + ln( Σ_j t_j^{-d} )`，d≈0.5 | 同形式，`memory_field.py:107-127` | 形式一致 |
| `B_i` | 基线激活，由历史/先验决定 | `B = 2 × salience`（`memory_field.py:117`） | **无理论依据**：salience 是内容显著度，不是基线激活 |
| 痕迹 | 每次呈现的真实时间戳 | 编码时刻 1 条 + `last_access` 复制 `min(access_count,16)` 条（`field.py:591-620`） | 合成痕迹，非真实访问史 |
| d | ≈0.5 | 0.5（`memory_field.py:45`） | 一致 |

**边界验算**（纯函数，now=1.8e9）：

| 边界 | 结果 | 判定 |
|---|---|---|
| t→0（刚写入） | `dt=max(1s)`，单痕迹 `ln(1)=0` → A=B | 不炸，但 1 秒内多次写入合并为同一时间点 |
| 无访问、有编码时刻 | A=`ln((now-encode)^-0.5)+B`；1 天前 sal=.5 → **A=-4.683，odds=0.137** | 注释声称「1 天前≈0.5」（`memory_field.py:47-49`）**与实测不符**；1 小时前 odds=0.438（注释称≈0.8） |
| 无编码时刻（t_ref=0） | 痕迹空 → A=B → odds=0.945，operational boost=1.227 | **边界 bug**：缺时间戳反而拿最高「新鲜度」加成；`Candidate.t_ref` 默认 0，任何漏填路径都命中 |
| 访问多但旧 | 16 次「1 小时前」→ odds=0.926；1 次「1 秒前」→ odds=0.979 | recency 压过 count，与 docs 的「访问越多越强」不总成立 |
| 访问 >16 次 | 复制上限 16，A 不再增长 | 次数饱和，与「幂律」的连续增长直觉不符 |
| 真实痕迹 >32 条 | `[-32:]` 截断；新增痕迹可使 A 下降 | 潜在非单调；当前合成路径不可达（最多 17 条） |
| 权重契约 | docs/03 §4.3 固定 `salience` 权重 0.20 | salience 同时进 raw(0.20)、tau、S、B → **实际权重不可从契约读出**，权重契约名存实亡 |

**判定**：部分实现、说法不准。「用 ACT-R 激活替代裸 `access_count`」不成立——`access_count` 仍是痕迹数量的唯一来源，A 只是它的单调变换加一个 recency 权重。

### 1.2 扩散：代码稳定，文档公式不稳定

- **代码**：`φ' = (1-α)φ + α·D⁻¹A·φ`（`memory_field.py:165-201`）。α∈[0,1] 时每点是「自身与邻居加权均值」的凸组合 ⇒ 无穷范数非扩张 ⇒ **有界、不发散**；2 节点实测 6 步收敛到均值 (.5,.5)。
- **文档**：docs/15 §1.1 写 `φ ← φ + min(α,1)·D·L_norm·φ`，等价于 `(1+α)φ − αD⁻¹Aφ`。二部图上 `D⁻¹A` 有特征值 −1，放大因子 `1+2α`；实测 α=.45 六步 `a=24.02, b=-23.02`，**指数增长**。
- **α 语义混淆**：docs/15 说「α = 空间衰减系数」（0.1/1/3），代码 α 是混合系数；若真传 3.0 会被 clamp 到 1，此时节点完全丢弃自身值，与「operational 烧得快」不是同一个意思。实现实际固定 α=0.45（`recall.py:392` → `field.py:541`），**三空间倍率没有进扩散**。
- **其他**：迭代 ≤3 只是成本上限，不是稳定性条件；孤立节点迭代中不衰减（φ 不变）；场不做质量守恒。
- **实证**：bench 报告 §6 显示场开 vs 场关：nDCG@10 −0.0436、p95 延迟 +108%、多跳 +0.20；D5 判据**未通过**（`docs/15:191`）。

**判定**：实现层面稳定（有界），但文档公式错误、参数未标定、学理收益未证明。

### 1.3 遗忘 `R=exp(-Δt/S)`：量纲对，标定缺

- **量纲**：S 为秒、Δt 为秒，比值无量纲 ✓。`S = 21d·(1+ln(1+n))·(0.5+sal)`，`Δt_eff = Δt × space_factor`（`forget.py:38-58`）。
- **标定数值**（n=0, sal=.5）：knowledge 约 **53 天**到 0.08；operational 约 **18 天**；identity 53 天仍 0.777（且 forget 过滤 `tier!='resident'`，identity 在遗忘路径基本不可达）。
- **折叠阈值是死参数**：`forget_fold_r=0.25` 只在体检里用（`audit.py:79`），forget 的折叠只对 `R<0.08` 的冷条目做（`forget.py:116-124,156-158`）。docs/03 §4.4「R<0.25 且 member≥4 折叠」说法不准；后果是摘要只在「几乎忘光」时才生成，**巩固不是持续过程**。
- **函数形式未选择**：检索侧用指数衰减（`score.py:192-194`，tau=30d×(0.5+sal)），遗忘侧用另一条指数（S=21d×…），ACT-R 项又是幂律——同一记忆同时被三条时间律打分。文献对保持函数形式的经典比较见 §3（幂律 vs 指数；本项目未做形式选择，也未对齐）。
- **21 天 / 0.08 / 0.25 / 0.8 均无出处**，必须真语料标定。

### 1.4 三空间 0.1 / 1.0 / 3.0：没有数值依据

- `critical_nodes`（`memory_field.py:233-251`）仍无调用点 → docs/07「关键节点永不归档」**未实现**；forget 的保护只有 `salience≥0.8` 与 `pinned`（`forget.py:78,118`）。
