  `Waiting for application shutdown` → `Application shutdown complete` → `Finished server process`，结果 `GRACEFUL_OK`。
  说明 `create_app()` 的 lifespan 收尾逻辑有效；Windows CLI 的 Ctrl+C 交互路径未做自动化（该平台信号限制）。
